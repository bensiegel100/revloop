# Support

Revloop is a community-supported open-source project.

## Bugs

Open a
[bug report](https://github.com/bensiegel100/revloop/issues/new?template=bug_report.yml)
with reproduction steps and your Revloop, VS Code, and operating-system
versions.

## Feature requests

Use the
[feature request form](https://github.com/bensiegel100/revloop/issues/new?template=feature_request.yml)
to describe the workflow problem and proposed behavior.

## Security

Report vulnerabilities privately as described in
[SECURITY.md](https://github.com/bensiegel100/revloop/blob/main/SECURITY.md).

## Scope

Support covers the Revloop VS Code extension, agent plugin, and bundled MCP
server. Questions about VS Code, Git, GitHub Copilot, or another coding harness
should be directed to that project's support channel.

## Response targets

- Review new bug reports and feature requests at least weekly.
- Acknowledge private security reports within seven days.
- Prioritize verified security issues and launch regressions for the next
  available patch release.

Patch releases are published as needed rather than on a fixed schedule.
