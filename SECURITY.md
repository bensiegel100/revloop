# Security Policy

## Supported versions

Security fixes are applied to the latest published Revloop version and the
current `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use
[GitHub private vulnerability reporting](https://github.com/bensiegel100/revloop/security/advisories/new)
to share the impact, reproduction steps, affected versions, and any suggested
mitigation.

Remove credentials, private source code, and unrelated personal information
from the report. Please allow time for investigation before publicly disclosing
the issue.
